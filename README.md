## 📱 О проекте

**Эко-Инициативы** — это мобильное приложение, созданное для объединения людей, заинтересованных в улучшении экологической ситуации. Платформа позволяет пользователям создавать экологические инициативы, привлекать единомышленников и получать поддержку сообщества.

### Основные возможности

- Регистрация и авторизация пользователей
- Создание экологических инициатив
- Модерация инициатив администратором
- Просмотр статуса инициатив (на модерации, одобрена, отклонена)
- Постановка лайков и оставление откликов
- Административная панель
- Отображение статистики (лайки и отклики)
- Защита паролей (хеширование)

## 🚀 Установка и запуск

### Требования

- Android Studio (последняя версия)
- JDK 11 или выше
- Устройство или эмулятор с Android 8.0+
- Аккаунт Firebase

### Шаги для запуска

1. **Клонировать репозиторий**

   git clone https://github.com/yourusername/ecoinitiatives.git
   cd ecoinitiatives

2. **Настроить Firebase**
   - Создать проект в Firebase Console
   - Добавить Android-приложение в проект
   - Скачать файл google-services.json и поместить в папку app/
   - Включить Authentication (Email/Password)
   - Включить Realtime Database

3. **Открыть проект в Android Studio**
   - File → Open → выбрать папку проекта
   - Дождаться синхронизации Gradle

4. **Запустить приложение**
   - Выбрать устройство или эмулятор
   - Нажать Run

## 🔐 Роли пользователей

### Пользователь

- Создание инициатив (отправка на модерацию)
- Просмотр списка одобренных инициатив
- Просмотр своих инициатив со статусами
- Постановка лайков и откликов
- Просмотр деталей инициатив

### Администратор

- Просмотр списка всех пользователей
- Удаление пользователей
- Просмотр всех инициатив
- Одобрение/отклонение инициатив
- Удаление инициатив
- Создание инициатив (сразу одобрены)

## 📋 Статусы инициатив

| Статус | Описание | Цвет |
|--------|----------|------|
| На модерации | Инициатива ожидает проверки | Оранжевый |
| Одобрена | Инициатива доступна всем | Зелёный |
| Отклонена | Инициатива не прошла проверку | Красный |
